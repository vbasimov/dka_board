## 3. Чего в выпуске нет

- Внешних зависимостей и сетевых вызовов — сознательно.
- Телеметрии, автообновления, серверов, мобильной версии.
- Реальных учётных данных: всё через переменные окружения контура.

## 4. Что проверить в контуре (не проверяется здесь)

1. `AA_CONFLUENCE` — сверка версий на живых страницах.
2. `AA_MAIL_CMD` — синхронизация настоящего ящика.
3. `AA_MCP_CMD` — поиск по настоящему индексу.
4. `AA_INDEX_CMD` — индексация писем после моста.
5. Установка вторым человеком по инструкции, без подсказок.

## 5. Если проверка не прошла

1. Зафиксировать пункт и фактическое поведение в [протоколе приёмки](acceptance-protocol.md), раздел «Замечания».
2. Исправление выходит новой версией архива; версия откатывается одной командой, если проблема блокирующая.
3. Пункт подписывается повторно после исправления.
