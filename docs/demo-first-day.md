# Проверка «первый день»: 15 минут

Сценарий для приёмки: что нажать и что должно получиться. Подходит и для проверки на своей машине, и для демонстрации коллеге.

## Подготовка (2 минуты)

1. Распакуйте архив в отдельную папку.
2. Запустите `start.cmd` (Windows) или `./start.sh`.
3. Откройте `http://127.0.0.1:7777`.

**Ожидаемо:** открывается «Сводка», сверху полоса счёта, ниже сворачиваемый блок «Как начать: шесть шагов». Если блок виден, значит интерфейс собран правильно.

Проверка без браузера:

```bash
curl -s http://127.0.0.1:7777/api/health      # {"ok":true,...}
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:7777/   # 200
```

## Шаг 1. Решение попадает в долги (2 минуты)

1. Раздел «Решения».
2. Впишите «Платежи передают события в Kafka», источник «протокол».
3. Нажмите «Зафиксировать».

**Ожидаемо:** строка появилась в таблице с бейджем «долг», на «Сводке» число «решения не в КАФО» стало 1.

4. Нажмите «В КАФО» в строке.

**Ожидаемо:** бейдж «в КАФО», на сводке снова 0.

## Шаг 2. Задача и горящий срок (2 минуты)

1. Раздел «Задачи».
2. Через быструю форму добавьте задачу со сроком сегодня.

**Ожидаемо:** задача в списке; на «Сводке» она попала в «Горящие сроки сегодня» с причиной «срок сегодня».

## Шаг 3. Почта (3 минуты, если настроена)

1. На «Сводке» нажмите «Обновить почту».

**Ожидаемо:** подпись «Писем получено: N», в колонке «Неотвеченные сообщения» появились письма с пометкой «не прочитано» там, где сервер не поставил `\Seen`.

2. Нажмите «Отправить письма в индекс».

**Ожидаемо:** подпись «Записано в индекс: N»; в папке данных появился каталог `письма-для-индекса` с `md`-файлами.

Если почта не настроена — шаг пропускается, остальное работает.

## Шаг 4. Проверка фактов (1 минута)

1. Раздел «Проверка фактов».
2. Нажмите «1» (подтвердить) на первой карточке.

**Ожидаемо:** карточка исчезла, счётчик остатка уменьшился. Клавиши 1/2/3 работают без мыши.

## Шаг 5. Свежесть КАФО (1 минута)

1. Раздел «КАФО» → «Сверить версии».

**Ожидаемо:** у каждой страницы бейдж «свежо» / «устарело» / «не сверено». Если Confluence недоступен — «не сверено», программа не виснет.

## Шаг 6. Схема и расхождения (2 минуты)

1. Раздел «Схемы».
2. Выберите файл `.drawio`, впишите интеграции вида «Сервис → Система», нажмите «Сверить».

**Ожидаемо:** три колонки: «есть в схеме, нет в КАФО», «есть в КАФО, нет в схеме», «требует взгляда».

## Шаг 7. Поиск по знаниям (1 минута)

1. Раздел «Поиск».
2. Введите «Kafka» и нажмите Enter.

**Ожидаемо:** список результатов с заголовком, типом источника и фрагментом. Пустой индекс — подсказка, а не пустой экран.

## Шаг 8. Ревью недели (1 минута)

1. Раздел «Ревью» → «Собрать ревью».

**Ожидаемо:** отчёт «что произошло / что не учли / что предлагаю», подпись «Сохранено: …», файл в папке данных, каталог `отчёты`.

## Шаг 9. Настройки (1 минута)

1. Раздел «Настройки» → «Проверить».

**Ожидаемо:** три отметки: данные, модель, источники. Красная отметка сопровождается текстом, что именно не так.

## Что считается успехом

- Все девять шагов выполнены без ошибок в консоли браузера.
- Сводка показывает реальные числа, а не нули при наличии данных.
- Ни одно действие не требует интернета.
- Время от запуска до первого результата — не больше 10 минут.

## Если что-то не так

| Симптом | Что проверить |
|---|---|
| Пустая сводка при наличии задач | порт и папку данных в настройках |
| «Не подключён» при поиске | `AA_MCP_CMD` или `AA_RAG_CMD` |
| «Не подключён» при почте | `AA_MAIL_CMD` |
| Все источники «не сверено» | `AA_CONFLUENCE` и доступ к метаданным |
| Ошибки в консоли браузера | скопируйте текст, пришлите — правлю |

Сквозные проверки, которые уже выполнялись автоматически: интерфейс в jsdom (12 проверок, включая клик по кнопкам почты и таблицу решений), 196 тестов в `assistant`, живой прогон API на временных данных.
