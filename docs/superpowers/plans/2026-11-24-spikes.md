# Спайки по рискам — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Проверить три главных риска проекта на реальных данных до начала основной разработки: разбор схем draw.io, сверку версий КАФО и способность хранилища работать в объёме.

**Architecture:** Три независимых модуля на Node.js без внешних зависимостей. Каждый модуль — чистая функция плюс тонкая обёртка ввода-вывода, поэтому проверяется без сети и без модели. Результат спайка — числа против порогов из требований, а не «вроде работает».

**Tech Stack:** Node.js 20+, `node:test` + `node:assert/strict`, без npm-зависимостей.

**Spec:** `docs/architecture.md`, `docs/requirements.md`, `docs/drawio-recognition-instruction.md`, `docs/cafo-cache-freshness-instruction.md`

## Global Constraints

- Ни одного внешнего сетевого вызова. В коде нет `fetch` на внешние адреса, нет `npm install`.
- Все файлы продукта — в папке `assistant/`, ниже `assistant/src` и `assistant/test`.
- Тесты запускаются командой `node --test` из `assistant/`.
- Пороги берутся из требований дословно: рёбра ≥ 70% корректных и 0 выдуманных; сверка ≤ 3 секунды; поиск ≤ 500 мс на 10 000 задач; старт ≤ 3 секунды.
- Русские тексты ошибок в интерфейсе, код и имена — латиницей.

## Review Focus

- Сжатая диаграмма: base64 внутри `<diagram>` — без распаковки половина реальных файлов не разберётся.
- Ребро без `source`/`target`: должно попадать в `unparsed`, а не привязываться к ближайшей вершине молча.
- Confluence не отвечает: ответ обязан быть «не сверено», а не «свежо» по дате кэша.
- Переименование страницы: поиск только по `page_id`.
- 10 000 задач: поиск не должен читать все файлы целиком.

- [ ] **Step 2: Положить фикстуры**

`plain.drawio` — одна страница: две вершины (`Kafka` со `shape=cylinder3`, `CRM` без стиля) и ребро `Kafka → CRM` с `dashed=1`.
`multi.drawio` — три `<diagram>` с разными `name`.
`compressed.drawio` — одна `<diagram>`, содержимое которой сжато: base64 от `deflateRaw(encodeURIComponent(xml))`.

- [ ] **Step 3: Написать падающие тесты**

```js
import test from 'node:test'
import assert from 'node:assert/strict'
import { readFileSync } from 'node:fs'
import { parseDrawio } from '../src/parse/drawio.js'

const read = (name) => readFileSync(new URL(`./fixtures/${name}`, import.meta.url), 'utf8')

test('разбирает простую схему: вершины, подписи, ребро', () => {
  const { diagrams } = parseDrawio(read('plain.drawio'))
  assert.equal(diagrams.length, 1)
  const [d] = diagrams
  assert.deepEqual(d.nodes.map(n => n.label), ['Kafka', 'CRM'])
  assert.equal(d.nodes[0].kind, 'хранилище')
  assert.equal(d.edges.length, 1)
  assert.equal(d.edges[0].dashed, true)
  assert.equal(d.unparsed.length, 0)
})

test('разделяет мультистраничный файл на отдельные диаграммы', () => {
  const { diagrams } = parseDrawio(read('multi.drawio'))
  assert.equal(diagrams.length, 3)
  assert.deepEqual(diagrams.map(d => d.name), ['Платежи', 'Расчёты', 'Риски'])
})

test('распаковывает сжатую диаграмму', () => {
  const { diagrams } = parseDrawio(read('compressed.drawio'))
  assert.equal(diagrams.length, 1)
  assert.ok(diagrams[0].nodes.length >= 2)
})

test('ребро без концов попадает в unparsed, а не выдумывается', () => {
  const xml = '<mxfile><diagram name="x"><mxGraphModel><root>' +
    '<mxCell id="2" value="A" vertex="1" parent="1"/>' +
    '<mxCell id="9" edge="1" style="" parent="1"/>' +
    '</root></mxGraphModel></diagram></mxfile>'
  const [d] = parseDrawio(xml).diagrams
  assert.equal(d.edges.length, 0)
  assert.deepEqual(d.unparsed.map(u => u.id), ['9'])
})
```

Expected: FAIL, `Cannot find module '../src/parse/drawio.js'`.

- [ ] **Step 5: Реализовать `parseDrawio`**

Функция: найти все `<diagram>`; если внутри нет `<mxGraphModel`, попробовать base64 → `inflateRaw` → `decodeURIComponent`; собрать вершины (`vertex="1"`), контейнеры (`swimlane` в стиле или наличие детей) как зоны; рёбра (`edge="1"`) с непустыми `source`/`target`; всё остальное — в `unparsed` с причиной. Тип узла — по таблице из инструкции, иначе `неизвестно`.

### Task 2: Сверка версии страницы КАФО

**Files:**
- Create: `assistant/src/cafo/freshness.js`
- Create: `assistant/test/cafo/freshness.test.js`

**Interfaces:**
- Produces: `freshnessOf(cached: {version:number, checkedAt:string|null}, remote: {version:number}|null, now: Date) -> { status: 'свежо'|'устарело'|'не_сверено', diff: number }`
- Produces: `fetchMeta(pageId, { timeoutMs }) -> Promise<{version:number}|null>` — при любой ошибке возвращает `null`, не бросает.

- [ ] **Step 1: Написать падающие тесты**

```js
import test from 'node:test'
import assert from 'node:assert/strict'
import { freshnessOf } from '../src/cafo/freshness.js'

test('совпадение версий — свежо', () => {
  assert.deepEqual(freshnessOf({ version: 12, checkedAt: null }, { version: 12 }), { status: 'свежо', diff: 0 })
})

test('рост версии — устарело с числом правок', () => {
  assert.deepEqual(freshnessOf({ version: 12, checkedAt: null }, { version: 14 }), { status: 'устарело', diff: 2 })
})

test('нет ответа — не сверено, никогда не свежо', () => {
  assert.equal(freshnessOf({ version: 12, checkedAt: '2026-11-24T09:00:00+03:00' }, null).status, 'не_сверено')
})

test('версия в источнике меньше сохранённой — устарело, отрицательная разница допустима', () => {
  assert.deepEqual(freshnessOf({ version: 14, checkedAt: null }, { version: 12 }), { status: 'устарело', diff: -2 })
})
```

### Task 3: Запуск помощника и объём хранилища

**Files:**
- Create: `assistant/src/store/tasks.js`
- Create: `assistant/src/server/app.js`
- Create: `assistant/test/store/tasks.test.js`
- Create: `assistant/test/server/app.test.js`

**Interfaces:**
- Produces: `createStore(dir) -> { add(task), byId(id), search(query), count() }`; каждая задача — файл `задачи/<id>.json`.
- Produces: `createServer({ store, host: '127.0.0.1' }) -> http.Server`, маршрут `GET /api/tasks?q=` возвращает JSON.

- [ ] **Step 1: Написать падающие тесты на хранилище (объём и скорость)**

```js
import test from 'node:test'
import assert from 'node:assert/strict'
import { mkdtempSync } from 'node:fs'
import { tmpdir } from 'node:os'
import { join } from 'node:path'
import { createStore } from '../../src/store/tasks.js'

test('держит 10 000 задач и ищет быстрее 500 мс', () => {
  const dir = mkdtempSync(join(tmpdir(), 'store-'))
  const store = createStore(dir)
  for (let i = 0; i < 10_000; i++) store.add({ id: `t-${i}`, title: `задача ${i}`, source: 'письмо' })
  assert.equal(store.count(), 10_000)
  const t0 = performance.now()
  const found = store.search('задача 9999')
  const ms = performance.now() - t0
  assert.ok(found.length >= 1)
  assert.ok(ms < 500, `поиск занял ${Math.round(ms)} мс`)
})

test('задача без источника отклоняется', () => {
  const dir = mkdtempSync(join(tmpdir(), 'store-'))
  const store = createStore(dir)
  assert.throws(() => store.add({ id: 't-1', title: 'без источника' }), /источник/)
})
```

- [ ] **Step 3: Реализовать хранилище с индексом в памяти и записью файлов**

Индекс строится один раз при старте чтением файлов; поиск — по массиву в памяти без диска. Запись — атомарная: временный файл и переименование.

- [ ] **Step 4: Написать тест сервера**

```js
import test from 'node:test'
import assert from 'node:assert/strict'
import { createServer } from '../../src/server/app.js'

test('слушает только 127.0.0.1 и отдаёт задачи', async () => {
  const store = { byId(){}, search(){ return [{ id: 't-1', title: 'тест' }] }, count(){ return 1 } }
  const server = createServer({ store })
  await new Promise(r => server.listen(0, '127.0.0.1', r))
  const { port, address } = server.address()
  assert.equal(address, '127.0.0.1')
  const res = await fetch(`http://127.0.0.1:${port}/api/tasks?q=тест`)
  const body = await res.json()
  assert.equal(body.items[0].id, 't-1')
  server.close()
})
```
