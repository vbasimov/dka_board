# Приёмка интерфейса

Отметки: `[x]` — проверено автоматически, `[ ]` — требует человека с браузером.

Список проверок, по которому принимается новый интерфейс. Каждый пункт — измеримый: либо есть, либо нет.

## 1. Структура и иерархия

- [ ] На первом экране «Сводка» видны четыре блока без прокрутки на 1366×768: счётная полоса, статусы КАФО, неотвеченные сообщения, горящие сроки.
- [ ] В каждом блоке не больше семи строк; остальное — по ссылке «показать все».
- [ ] На экране не больше одного акцентного цвета и не больше трёх размеров шрифта для текста.
- [ ] Числа в счётной полосе крупнее подписей минимум вдвое.

## 2. Состояния

- [ ] Пустое состояние каждого блока содержит короткую инструкцию и одно действие.
- [ ] Ошибка загрузки объясняет, что случилось, и что сделать, без технического кода.
- [ ] Данные с устаревшим источником помечены текстом, а не только цветом.

## 3. Клавиатура

- [ ] Все интерактивные элементы достижимы Tab, фокус видим.
- [ ] В квизе фактов работают клавиши 1/2/3.
- [ ] Escape закрывает любое открытое окно подтверждения.
- [ ] Порядок обхода совпадает с визуальным порядком.

## 4. Доступность

- [ ] Контраст текста к фону ≥ 4,5:1, вторичного текста ≥ 4,5:1.
- [ ] Каждый бейдж статуса имеет текстовую подпись рядом.
- [ ] Масштаб 200% не ломает вёрстку и не обрезает текст.
- [ ] У кнопок-иконок есть доступные имена.

## 5. Скорость и вес

- [x] Ни одного внешнего запроса: шрифты системные, стили и скрипты внутри.
- [ ] Первый экран отрисовывается без ожидания данных: скелетон не дольше 300 мс.
- [ ] Нет анимаций дольше 150 мс.

## 6. Тесты

- [ ] Каждый рендер-модуль покрыт тестом: обычное состояние, пустое, экранирование.
- [ ] Тест на отсутствие внешних ресурсов в HTML.
- [ ] Тест на наличие всех разделов и клавиатурных подсказок.
- [x] `node --test` зелёный, число тестов не меньше прежнего.

## 7. Плотность

- [ ] Высота строк списков и таблиц 40–44 px.
- [ ] Базовый ритм отступов кратен 4 px; основной — 8 и 12.
- [ ] На 1366×768 нет горизонтальной прокрутки.

## 8. Что считается провалом

- Эмодзи в интерфейсе, градиенты, декоративные тени.
- Скрытые основные действия за меню «…».
- Модальные окна там, где хватает действия в строке.
- Цвет как единственный носитель смысла.
- Текст-заглушка вместо данных в макете.
