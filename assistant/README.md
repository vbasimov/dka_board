# Ассистент архитектора

Локальная программа для одного человека. Работает без интернета, данные хранит в обычной папке.

## Как запустить

1. Установите Node.js 20 или новее (если его нет; обычно он уже стоит вместе с gigacode).
2. Распакуйте архив в отдельную папку, например `Документы\Ассистент`.
3. Запустите:
   - Windows: двойной клик по `start.cmd`;
   - macOS и Linux: `./start.sh` (или `sh start.sh`).
4. Откройте в браузере `http://127.0.0.1:7777`.

Данные создаются в папке `assistant/.data` рядом с программой. Чтобы выбрать другую папку, задайте переменную `AA_DATA`, а для сверки версий Confluence — `AA_CONFLUENCE` с адресом хранилища.

## Что внутри

- `bin/serve.js` — запуск локального помощника;
- `src/` — разбор схем, кэш КАФО, факты и версии, черновики, ревью;
- `ui/` — интерфейс: семь разделов;
- `test/` — тесты, запуск `node --test`.

## Проверка

```
cd assistant
node --test
```

Тесты не требуют интернета и установки пакетов.

## Сборка архива

```
node install/build.js
```

Результат: `dist/architect-assistant.zip`.
